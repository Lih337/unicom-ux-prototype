# 💬 Unicom: Chat App UI/UX Design

A chat app designed in **Figma** and built as a **clickable prototype**.

---

## ✨ Features Designed

- **Messaging:** one-to-one chat
- **Posting pictures:** an Instagram-style feed
- **Calls:** a call screen
- **Add friends:** find and add people
